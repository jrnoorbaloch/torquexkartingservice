A giant spec or race-position number — 80px/700 value over an uppercase caption. The brand's way of making performance numbers a display element.

```jsx
<SpecCell value="2.85s" label="0–100 km/h" />
<SpecCell value="340" label="Top speed km/h" />
<SpecCell value="P1" label="Italian GP" tone="race" />
```

`tone="race"` colors the value Rosso Corsa — reserved for F1 finishing positions. Default is white.
