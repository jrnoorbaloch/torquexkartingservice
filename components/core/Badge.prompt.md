Small uppercase pill badge — the only Torque X element that uses pill geometry (everything else is sharp 0px).

```jsx
<Badge>New</Badge>
<Badge tone="primary">Formula 1</Badge>
<Badge tone="light">Preowned</Badge>
```

Tones: `default` (elevated grey on dark), `primary` (Rosso Corsa), `info` / `success` / `warning` (semantic), `light` (for white editorial bands). Keep label short and uppercase.
