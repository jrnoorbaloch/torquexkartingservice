The signature Torque X CTA — Rosso Corsa fill, sharp 0px corners, uppercase 1.4px-tracked label; use scarcely for the single primary action on a band.

```jsx
<Button onClick={configure}>Configure</Button>
<Button variant="outline-on-dark">Discover</Button>
<Button variant="outline-on-light">Book a test drive</Button>
<Button href="/dealers">Find a dealer</Button>
```

Variants: `primary` (default, Rosso Corsa), `primary-active` (press state, darker red), `outline-on-dark` (transparent + 1px white border, for dark hero bands), `outline-on-light` (1px ink border, for white editorial bands). Never use rounded/pill geometry — sharp corners are the brand. Height is 48px (WCAG AAA tap target).
