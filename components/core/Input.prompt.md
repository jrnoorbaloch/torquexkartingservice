Text input — 48px tall, 4px corners (the single rounded form element in the system), 1px hairline border, Hypersail-yellow focus ring.

```jsx
<Input theme="dark" label="Email" placeholder="you@torquex.com" />
<Input theme="light" placeholder="Search models" />
```

`theme="dark"` (default) for dark canvas; `theme="light"` for white editorial bands. Pass `label` for an uppercase field label above the field.
